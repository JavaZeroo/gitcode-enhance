# v0.3.4 — 内存与讨论区性能优化

发布日期：2026-11-03。GitHub 分发版本为 v0.3.4；Greasy Fork 更新包已生成，原条目同步待完成（发布时浏览器工具无法可靠识别当前网址，中止了自动操作）。

## 变化

- 未使用图标只保留 SVG 文本，按需重建，减少原节点与已移除容器的长期保留。
- PR 讨论区默认按阅读位置展开；设置中可恢复全部展开。后台暂停，同一按钮只自动尝试一次，离开页面清理任务。
- 搜索索引不重复保留原始 diff；关闭后释放结果和面板引用，一分钟后释放复用缓存，路由切换立即清理。拦截记录限定最近 100 条。
- 修复全页关系选择器放大讨论页样式重算的问题；动态去干扰只扫描新增子树。

## 验证与限制

- 25 项 Node 回归测试、语法检查、构建和差异格式检查通过。
- 独立 Chrome 强制 GC 测试中，仍存活的原始未使用 symbol 从 1600 个降到 0；缓存图标可恢复，移除原容器后仍可恢复；滚动及取消调度断言通过。
- 固定 10 秒讨论页样本中，样式重算均值下降约 73%。这是特定页面的局部指标，不是全站加载时间下降。
- 图标序列化会增加字符串存储及裁剪/恢复时间。合成样本不能换算为完整页面节省固定 MB；真实站点的主题、快速滚动和回复框可用时间仍需补充验收。
- 单个折叠块仍由站点整体展开，不会收起已展开内容。未解决延迟差异补全、增量索引或站点虚拟列表重绘，也未宣称彻底解决回复框迟迟不出现。

测量详情：[CPU / 网络 profiling](../performance/2026-11-03-profiling.md)、[内存与恢复对照](../performance/2026-11-03-memory.md)、[v0.3.4 源码复验结果](v0.3.4-memory-check.json)。源码 SHA-256 按测量时本地文件计算，Git 的换行规范化可能改变字节哈希；发布附件的校验值另见 `SHA256SUMS.txt`。
