GitCode / AtomGit 增强（MIT 开源）

适用于 gitcode.com，建议使用 Tampermonkey 安装。请只启用一份本脚本，避免与旧版或本地开发加载器重复运行。

主要功能
- PR 文件改动页按 Ctrl+F 搜索已取得的差异内容，包括屏幕外但已索引的文件；Enter / Shift+Enter 切换结果，Esc 关闭。
- 搜索后标黄已渲染差异中的全部匹配词；当前结果使用橙色和行边框，滚动加载代码时自动补充高亮。
- 支持区分大小写、仅搜索新增/删除行，并显示索引覆盖范围。
- 悬浮设置按钮、评审工具栏和查找栏支持六个位置；设置和回到顶部默认位于左下角，评审工具默认收起；保留已有自定义位置。
- 文件路径筛选、前后文件跳转、当前路径复制、专注模式及评论自动展开。
- 去广告和去干扰、轻度字体美化、可选图标裁剪与网络拦截，所有功能可独立设置。

0.3.3 更新
搜索优先当前阅读文件并回绕；再次 Ctrl+F 更新起点。搜索框先显示，索引分批准备；等待期间可输入，Enter 会在结果就绪后跳转。首次站内跳转搜索仍可能需要网络等待。

使用说明
点“⚙ 设置”、顶栏齿轮或 Alt+G 打开设置。默认轻量级不拦截网络；极致级会关闭部分 AI、客服等功能，按需启用。

已知限制
搜索范围是服务器提供的 diff 新增、删除和上下文行，不是未改动文件全文。二进制或被服务器截断的差异会提示可能遗漏。当前不会自动补全 load diff 文件，也不会自动将手动加载的差异补入已有搜索索引。GitCode 自身会回收离屏代码视图，回滚时可能重绘，本脚本尚未改变该行为。GitCode 改版可能使功能失效。
性能收益随页面、网络与浏览器变化，不承诺全站加载提速。搜索高亮使用现代浏览器的 CSS Highlight API。
